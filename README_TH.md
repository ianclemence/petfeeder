# ระบบให้อาหารสัตว์อัตโนมัติ

> [English README](README.md) | [คู่มือติดตั้งภาษาไทย](SETUP_TH.md) | [English Setup Guide](SETUP.md)

ระบบให้อาหารสัตว์เลี้ยงอัตโนมัติที่ใช้ Arduino ร่วมกับเซ็นเซอร์อัลตราโซนิก HC-SR04 ในการตรวจจับเมื่อสัตว์เลี้ยงอยู่ใกล้ และเปิดประตูอาหารอัตโนมัติด้วยเซอร์โว

**ไม่มีตัวจับเวลา** — ทำงานด้วยการตรวจจับระยะทางเท่านั้น พร้อมระบบ cooldown เพื่อป้องกันการให้อาหารมากเกินไป

## สำหรับนักศึกษา — สิ่งที่คุณจะได้เรียนรู้

| แนวคิด | ไฟล์ | สิ่งที่สอน |
|---------|-------|-----------|
| **โค้ดแบบโมดูลาร์** | `firmware/*.h` | การแบ่งโค้ดเป็นไฟล์ด้วย `#include` |
| **การวัดระยะด้วยอัลตราโซนิก** | `sensor.h` | คลื่นเสียงกับการวัดระยะ |
| **การควบคุมเซอร์โว** | `servo_control.h` | สัญญาณ PWM กับมุมมอเตอร์ |
| **โปรโตคอล Serial** | `commands.h` | การสื่อสารระหว่างอุปกรณ์กับ PC |
| **เซิร์ฟเวอร์ HTTP** | `server.py` | พื้นฐานระบบเครือข่าย Python |
| **การบันทึก CSV** | `server.py` | การจัดเก็บและวิเคราะห์ข้อมูล |
| **JSON API** | `server.py` | การออกแบบ REST endpoint |
| **แดชบอร์ดเรียลไทม์** | `index.html` | การ poll ข้อมูล กราฟ canvas และ DOM |

## อุปกรณ์ฮาร์ดแวร์ที่ต้องการ

| อุปกรณ์ | หน้าที่ | พิน |
|---------|--------|-----|
| Arduino UNO (CH340 clone) | ไมโครคอนโทรลเลอร์ | USB ต่อ PC |
| HC-SR04 Ultrasonic Sensor | ตรวจจับระยะทางสัตว์ | Trig=D9, Echo=D10 |
| SG90 Micro Servo | เปิด/ปิดประตูอาหาร | Signal=D6 |
| สาย jumper (M-M) | การเชื่อมต่อ | — |
| สาย USB Type-B | จ่ายไฟ + โปรแกรม | — |

## คู่มือการติดตั้ง

ดูรายละเอียดเพิ่มเติมได้ที่ [SETUP_TH.md](SETUP_TH.md)

### ขั้นตอนที่ 1 — ติดตั้ง dependencies ของ Python

```bash
cd bridge
pip install -r requirements.txt
```

### ขั้นตอนที่ 2 — อัปโหลดเฟิร์มแวร์

เฟิร์มแวร์ได้ถูกอัปโหลดไปยัง Arduino บน COM4 แล้ว หากต้องการอัปโหลดใหม่:

```bash
arduino-cli compile --fqbn arduino:avr:uno firmware/pet_feeder/pet_feeder.ino
arduino-cli upload --fqbn arduino:avr:uno --port COM4 firmware/pet_feeder/pet_feeder.ino
```

### ขั้นตอนที่ 3 — เริ่มต้น Dashboard

```bash
cd bridge
python server.py
```

จากนั้นเปิด **http://localhost:8080** ในเบราว์เซอร์

## วิธีการทำงาน

### เฟิร์มแวร์ (Arduino)

1. เซ็นเซอร์ HC-SR04 วัดระยะทางทุก 500 มิลลิวินาทีโดยใช้คลื่นอัลตราโซนิก
2. หากตรวจจับสัตว์ได้ภายใน 20 ซม. และ cooldown 15 วินาทีผ่านไปแล้ว:
   - เซอร์โวเปิดเป็น 90° (ให้อาหาร)
   - ค้างไว้ 3 วินาที
   - เซอร์โวปิดกลับเป็น 0°
3. ส่งข้อมูลทั้งหมดไปยัง PC ผ่าน Serial ที่ 115200 baud

### Bridge (Python)

1. เปิด COM4 และอ่านข้อความจาก Arduino
2. เก็บค่าระยะทางและสถานะการให้อาหารล่าสุดในหน่วยความจำ
3. เสิร์ฟหน้า Dashboard บนพอร์ต 8080
4. ส่งคำสั่ง (feed/stop) จาก Dashboard ไปยัง Arduino
5. บันทึกเหตุการณ์ทั้งหมดลงไฟล์ CSV
6. แสดงสถิติการให้อาหาร (จำนวนวันนี้, ค่าเฉลี่ย)

### Dashboard (HTML/JS)

1. ดึงสถานะจาก Python bridge ทุกวินาที
2. แสดงระยะทางพร้อมสี (เขียว = สัตว์อยู่ใกล้, แดง = อยู่ไกล)
3. แสดงกราฟระยะทางแบบเรียลไทม์
4. แสดงสถิติการให้อาหาร
5. ปุ่ม manual feed สำหรับทดสอบ

## การปรับแต่ง

แก้ไขไฟล์ `firmware/pet_feeder/config.h`:

| พารามิเตอร์ | ค่าเริ่มต้น | คำอธิบาย |
|-------------|-----------|---------|
| `detection_range_cm` | 20.0 | สัตว์ต้องอยู่ใกล้แค่ไหน (ซม.) |
| `cooldown_seconds` | 15 | เวลาขั้นต่ำระหว่างการให้อาหาร (วินาที) |
| `zone1_close_cm` | 15.0 | ระยะโซน portion เต็ม (ซม.) |
| `zone2_medium_cm` | 30.0 | ระยะโซน portion ครึ่ง (ซม.) |
| `ZONE_FULL_ANGLE` | 90 | ประตูเปิดกว้างสำหรับ portion เต็ม (องศา) |
| `ZONE_HALF_ANGLE` | 45 | ประตูเปิดกว้างสำหรับ portion ครึ่ง (องศา) |
| `HOLD_TIME_MS` | 3000 | ประตูเปิดค้างไว้นานแค่ไหน (มิลลิวินาที) |

## ข้อผิดพลาดที่พบบ่อย (และวิธีแก้)

| ข้อผิดพลาด | สิ่งที่เกิดขึ้น | วิธีแก้ |
|------------|---------------|--------|
| **พอร์ต COM ผิด** | "Cannot open COM4" | ตรวจ Device Manager หาพอร์ต Arduino, อัปเดตใน `server.py` |
| **เซอร์โวสั่น** | ประตูเปิด/ปิดเอง | ใช้ไฟเลี้ยง 5V แยกสำหรับเซอร์โว |
| **ระยะค้างที่ 999** | ไม่ตรวจจับสัตว์เลย | ตรวจสอบการเดินสาย TRIG/D9 และ ECHO/D10 |
| **เซอร์โวไม่ขยับ** | — | สายแดงต่อ 5V, น้ำตาลต่อ GND, ส้มต่อ D6 |
| **Dashboard ไม่โหลด** | หน้าจอแสดง "Connecting" | ตรวจสอบว่า `python server.py` กำลังทำงานอยู่ |
| **ไม่พบ CH340** | Arduino ไม่ถูกตรวจจับ | ติดตั้งไดร์เวอร์ CH340 จากลิงก์ด้านบน |

## การแก้ไขปัญหา

| ปัญหา | วิธีแก้ |
|-------|--------|
| "Cannot open COM4" | ปิด Arduino Serial Monitor หรือโปรแกรม serial อื่นๆ |
| ไม่มีค่าระยะทาง | ตรวจสอบการเดินสาย TRIG/D9 และ ECHO/D10 |
| เซอร์โวไม่ขยับ | ตรวจสอบไฟเลี้ยงเซอร์โว (5V) และสายสัญญาณ (D6) |
| Dashboard แสดง "Disconnected" | ตรวจสอบว่า `python server.py` กำลังทำงานอยู่ |
| CH340 ไม่ถูกตรวจจับ | ติดตั้งไดร์เวอร์ CH340 จาก https://www.wch-ic.com/downloads/CH341SER_EXE.html |
